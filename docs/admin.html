Public Data Editors

公開データ編集

公開ページに表示される3つのデータを編集します。保存すると対応するJSONへ反映されます。

contributors-data.json ご協力者様 トップページのご協力者様チャンネル欄を編集します。 streamers-data.json 配信者紹介 配信中心の方を紹介するページを編集します。 video-library-data.json 動画リンク集 キャラ別動画、投稿者、チャンネル情報を編集します。

Background Media

左メニュー背景

画像または動画のURL/パス、透過率、ループ、表示位置を編集します。左メニューと各ヘッダーを切り替えて設定できます。
